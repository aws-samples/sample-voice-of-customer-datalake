# Orchestration templates

The agent orchestration templates (the engineering agents' cards and skills, the flows, the seeded automations, the
gate packs and the eval cases) live in
[`voc-datalake/templates/orchestration/`](../../voc-datalake/templates/orchestration/README.md), beside the code that
compiles them (`voc-datalake/lambda/engineering/orchestration/`). Validate them with `npm run orchestration:validate`.
