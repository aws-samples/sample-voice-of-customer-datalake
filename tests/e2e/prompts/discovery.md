Use the aidlc-discovery skill to run a complete Discovery workshop in unattended mode, as configured in config.md in this folder.

Run all five phases in order (Signals, Working Backwards, Prototype, Validate, Handoff) on the customer feedback in discovery/data/. There is no product codebase in this folder, so skip the current-product map. Do not stop to ask questions or confirm checkpoints. Finish with the Handoff, print the AI-DLC start command, and do not start AI-DLC.
